## Title: 
pulse-Basic-Java-Rougelike

## Description:
A very basic rougelike game to show understanding of fundamentals of Java

## Detailed description and delimitations:
The game is small enough that it does not need any functionality for changing a players name

The doors are created in the rooms, hence there is technically 2 version of each door, with different locations. Can be locked/unlocked with no need for them to be the same. 

The game setup is done in a seperate class. The code would be less readable if we were to put all of that functionality into only one method in the main class
